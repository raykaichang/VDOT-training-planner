# 跑步機速度／坡度換算文獻驗證

## 驗證結論

20 組案例全部與 HillRunner 公開換算表的原始格值一致。這只代表「查表實作正確」，不代表 20 組都已被生理研究驗證。

Foreman、Lee 與 Lundstrom 的驗證研究支持範圍為：受訓跑者、次最大努力、平地等效配速 6:45–10:00/mi（約 4:12–6:13/km）、坡度 0–4%。坡度超過 4% 時，研究觀察到換算後的實際運動強度仍會增加。因此程式會將超出完整範圍的結果標成警示，但仍保留 HillRunner 查表值。

## 來源

- [HillRunner Treadmill Pace Conversions](https://www.hillrunner.com/calculators/treadmill-pace-conversions/)：20 組預期格值的直接來源。
- [HillRunner FAQ](https://www.hillrunner.com/treadmill-pace-conversions-faq/)：說明表格是實務起點，不是可精確擬合的單一公式。
- [Foreman et al. validation study](https://pmc.ncbi.nlm.nih.gov/articles/PMC10707652/)（[DOI](https://doi.org/10.1123/ijspp.2021-0021)）：0–4% 與配速／族群／強度適用範圍，以及高坡度限制。

## 執行方式

```powershell
npm run test:treadmill:literature
```

每支情境腳本也能獨立執行，例如：

```powershell
node scripts/treadmill-validation/10-8mph-4pct.mjs
```

總跑器另外檢查：案例恰好 20 組、ID 不重複、mph 與 km/h 都有覆蓋、速度涵蓋 5–12 mph，並且坡度 0–10% 每個整數值都至少出現一次。
